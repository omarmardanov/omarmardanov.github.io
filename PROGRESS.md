# cv-de — progress log

Портфолио для поиска работы в Германии (Design Engineer / AI-augmented Product
Designer). Отдельно от `pet/uxui` (там — фриланс-клиенты, здесь — hiring managers).
Контекст и связи с другими заметками — в памяти Claude, `germany-job-search-context`.

## Структура на диске

```
cv-de/
  index.html          — лендинг: имя, позиционирование, список кейсов
  resume.html          — резюме, ATS-safe (один столбец, обычный текст,
                          печатается в PDF), см. отдельный раздел ниже
  cases/litera.html   — первый (и пока единственный) кейс
  assets/ids/…         — вендоренный исходник Intuition Design System
                          (intuition.team/ru/ids), CSS + шрифт Inter,
                          MIT-лицензия, скопирован по их же принципу
                          «просто скопируй код, не подключай как зависимость»
  assets/style.css     — маленькие свои классы поверх IDS (.dek, .table-scroll,
                          .mockup-row/.mockup-phone/.mockup-wide — ряд из 1–4
                          картинок, флекс с wrap)
  assets/img/litera/   — картинки для кейса Litera
  case-litera.md       — черновик кейса на английском, исходник для litera.html
                          (можно считать устаревшим относительно .html)
```

Формат портфолио — публичная ссылка (не PDF), решение зафиксировано в разговоре.
Резюме — отдельный документ (`resume.html`), ATS-safe, печатается в PDF браузером.

## Резюме (`resume.html`)

Собрано с нуля в этой же сессии, ATS-safe (один столбец, обычный текст без
картинок-вместо-текста, `@page`-CSS под печать), **проверено печатью в
настоящий PDF через CDP (`Page.printToPDF`), не на глаз — влезает на одну
A4-страницу** после подгонки шрифта/отступов (13px базовый шрифт, компактные
интервалы). Если резюме ещё раз будет расти контентом — снова проверять
печатью, а не рендером в браузере: разница в ширине контента (окно vs
печатный лист) даёт разное число переносов строк, визуально «влезает» не
значит влезает при печати.

Ключевые решения по содержанию:

- Язык — только английский. Фото — без фото. Формат — только ATS-safe
  (визуальную версию не делали).
- Заголовок роли — «Design Engineer», хотя термин редкий на европейских
  джоб-бордах (чаще ищут «Product Designer»/«UX-UI Designer») — решили в
  пользу яркости/дифференциации, не охвата по ключевым словам.
- VEA (Sep 2022 – Present) — реальный текущий работодатель, agency, Москва
  (описана как «Digital design & development agency», не «IT-accredited
  company» — это российский налоговый термин, для Европы ничего не значит).
  Роль внутри — прогрессия UX/UI Designer → Design Engineer (переход
  примерно летом 2025), подана одним блоком, не двумя периодами.
- Опыт (`<ul>` под VEA) переписан с формата «кейсы по проектам» на формат
